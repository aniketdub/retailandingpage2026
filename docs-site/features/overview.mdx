RetAI is organised into modules. Each one is a screen in the left sidebar, and each one can be granted or revoked per role.

## Default access by role

<Note>
  Owners always see every module and cannot be restricted. The table below is the starting point for the two configurable roles — change any of it in [Roles & permissions](/admin/roles-and-permissions).
</Note>

| Module | Doctor | Receptionist |
| --- | :---: | :---: |
| Overview | ✅ | ✅ |
| AI Calendar | ✅ | ✅ |
| All Patients | ✅ | ✅ |
| WhatsApp Inbox | ✅ | ✅ |
| AI Receptionist | ✅ | ✅ |
| Leads Pipeline | ✅ | ✅ |
| Services | ✅ | ✅ |
| Before & After | ✅ | ✅ |
| Treatment Packages | ✅ | ✅ |
| At-Risk Patients | ✅ | ❌ |
| Consultations & Rx | ✅ | ❌ |
| Billing | ✅ | ❌ |
| Inventory | ✅ | ❌ |
| Staff | ❌ | ❌ |

Two defaults are deliberate and worth naming:

- **Reception gets the photo library and packages.** They capture the photos and they sell the packages. Locking them out creates a bottleneck at the doctor.
- **Reception does not get prescriptions.** Prescribing is clinical. An owner can grant it, but it is off until they do.
