## List appointments

`GET /api/appointments`

<ParamField query="from" type="string">ISO 8601. Start of the range.</ParamField>
<ParamField query="to" type="string">ISO 8601. End of the range.</ParamField>
<ParamField query="clinician_id" type="string">UUID.</ParamField>
<ParamField query="patient_id" type="string">UUID.</ParamField>
<ParamField query="status" type="string">`tentative`, `confirmed`, `checked_in`, `completed`, `no_show`, `cancelled`.</ParamField>
<ParamField query="limit" type="integer" default="100">Maximum 500.</ParamField>

```bash
curl "https://www.retentionos.tech/api/appointments?from=2026-08-14T00:00:00%2B05:30&to=2026-08-15T00:00:00%2B05:30" \
  -H "Cookie: <session cookie>"
```

## Update an appointment

`PATCH /api/appointments/{id}`

<ParamField body="status" type="string">Any valid status.</ParamField>
<ParamField body="starts_at" type="string">ISO 8601. Reschedules; `ends_at` recomputes from the service duration unless supplied.</ParamField>
<ParamField body="ends_at" type="string" />
<ParamField body="clinician_id" type="string">Reassigns the clinician.</ParamField>
<ParamField body="notes" type="string" />

```bash
curl -X PATCH "https://www.retentionos.tech/api/appointments/3c6e0b8a-9c15-4f2d-8b1e-71c4f0a2d9e5" \
  -H "Content-Type: application/json" \
  -H "Cookie: <session cookie>" \
  -d '{"status":"completed"}'
```

### Side effects

Updating an appointment is not an inert write:

| Change | Triggers |
| --- | --- |
| `status` → `completed` | Post-visit follow-up queued; aftercare sent if configured; package session incremented; consumables deducted |
| `status` → `cancelled` | Pending reminders cancelled; Google Calendar event removed; slot freed |
| `starts_at` changed | Reminders re-queued; Google Calendar event moved |
| `clinician_id` changed | Google Calendar event moves between calendars |

<Warning>
  Marking `completed` deducts stock and recognises package revenue. Do not use it as a generic "seen" flag — it is a commercial and clinical event.
</Warning>

## Errors

| Code | Cause |
| --- | --- |
| `400` | Invalid status transition, unparseable date, or unresolved clinic scope |
| `403` | Role lacks the Calendar module |
| `404` | No such appointment **in your clinic** |
